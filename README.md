# 🎨 Quietness  


**Quietness** is an experimental project focused on practicing and improving animation skills in web development.  
The main goal is to explore different animation techniques, smooth transitions, and interactive UI elements.  

---

## ✨ Features  
- 🎬 Various animation experiments  
- ⚡ Smooth transitions between components  
- 🖼️ Interactive UI elements  
- 🎨 Practice with libraries and custom animation logic  

---

## 🚀 Tech Stack  
- [Next.js](https://nextjs.org/)  
- [TailwindCSS](https://tailwindcss.com/)  
- [Framer Motion](https://www.framer.com/motion/)  
- [GSAP](https://greensock.com/gsap/)  

---

## 🔧 Getting Started  

### 1. Clone the repository  
```bash
git clone https://github.com/qu1etness/quietness.git
cd quietness
```

### 2. Install dependencies  
```bash
npm install
```

### 3. Start development server  
```bash
npm run dev
```

The project will be available at:  
👉 http://localhost:3000
